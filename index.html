📖 Resumo Rápido de Símbolos & Notação Peter Chen
Tabela de consulta rápida de toda a sintaxe suportada pelo parser:

NomeEntidade { ... } Entidade Forte (Retângulo) entidade fraca Nome { ... } Entidade Fraca (Retângulo Duplo)

📌 1. Entidades Fortes e Tipos de Atributos
Define uma entidade regular (retângulo) com seus atributos. Prefixos: * (Chave Primária), ~ (Derivado), ++ (Multivalorado), e Nome[Sub1, Sub2] ou Nome(Sub1, Sub2) para Atributos Compostos.
Exemplo: Entidade Forte e Atributos 
Aluno {
  *CPF,
  Nome[PrimeiroNome, Sobrenome],
  ~Idade,
  ++Telefones
}
⛓ 2. Entidades Fracas e Chaves Parciais
Entidades que dependem de uma entidade identificadora. Retângulo duplo visual. Use _Nome_ (undescores nas pontas) para chave parcial (discriminador).
Exemplo: Entidade Fraca 
entidade fraca Dependente {
  _NomeDependente_,
  Parentesco
}
🔗 3. Relacionamentos, Cardinalidades e Linha Dupla
Associações com cardinalidades (1:1, 1:N, N:N). Use relacionamento fraco para entidades fracas, ou prefixos como Obrig... / obrigatorio ... para Participação Total (Linha Dupla).
Exemplo: Relacionamentos 
pertence (Curso N : 1 Area)
ObrigCompoe (Curso 1 : N Modulo)
relacionamento fraco compoe (Curso 1 : N Modulo)
💎 4. Relacionamentos com Atributos
Em associações N:N, você pode definir atributos próprios do relacionamento dentro de chaves { }.
Exemplo: Atributo no Losango 
matricula (Aluno N : N Curso) {
  DataMatricula,
  Pago
}
🔄 5. Auto-Relacionamentos (Recursivos) e Papéis (Roles)
Quando a mesma entidade se conecta duas vezes ao relacionamento, use [papel] para diferenciar cada ponta.
Exemplo: Auto-Relacionamento 
integra (Area [integrante] N : 1 Area [integrada])
🧬 6. Especialização e Generalização EER
Hierarquias de herança com círculo central (⊂). Tipos: d (Disjunta), o (Sobreposta) ou u (União/Categoria).
Modificadores: total = linha dupla (toda superentidade obriga pertencer a uma subclasse); sem modificador ou parcial = linha simples.
Atributo Definidor: [NomeAtrib] opcional ao final — exibido ao lado da linha superclasse→círculo.
Parcial + Disjunta + Atributo Definidor 
especializacao d (Funcionario -> Mensalista, Horista) [TipoContrato]
Total + Sobreposta (linha dupla) 
especializacao total o (Pessoa -> Aluno, Professor)
Categoria / União (u) 
categoria u (Veiculo -> Carro, Moto)
💬 7. Comentários e Comandos de Console
Linhas com // ou # são comentários. O console aceita comandos incrementais de uma linha.
Exemplo: Comandos de Console 
// Comentário ignorado
criar entidade Departamento
adicionar atributo Email em Aluno
deletar entidade Curso
